# 设备验收清单

优先在 OPPO / vivo / 一加 Android 8+ 设备上验证。以下是待执行的检查清单，不代表每一款设备均已通过。

- 飞行模式下可打开四个 Tab，查看已有记录并新建手记；没有示例模式或虚构使用时长。
- 未授权时显示空状态及权限指引；开启权限后尝试导入近期记录。
- 前台使用测试应用至少两分钟，返回刷新后时长增加；重复刷新不重复累计。
- 锁屏和关机时间不会计入前台使用；观察迟到事件在下一次刷新后的修正。
- 今天、近 7 天、近 30 天、自选日期边界正确；点击柱子后排行和应用详情一致。
- 近 7 / 30 天平均显示在总时长卡片内，长时长在窄屏不换行。
- 一天按时间倒序，系统桌面及不足一分钟片段隐藏，再合并同应用；两分钟以内空白不显示补记卡片。
- 睡眠推测可修改或取消，半夜短暂使用不会把睡眠切碎；缺失依据时不生成。
- 手记支持跨日、分类、备注、图片和搜索；点开先看详情，编辑取消、保存和删除行为正确。
- 添加图片后旋转、返回、取消再重开，原记录没有被提前修改。
- 足迹可按应用、类型、日期组合筛选并继续加载，更新不会新增安装卸载。
- 卸载其他应用后历史保留，同包名重装后继续累计；强制停止本工具后漏收到的事件不会被伪造。
- 撤销使用权限仍能查看历史，重新开启后继续采集。
- 设备重启解锁、省电、后台冻结、自启动开关变化时，观察最近采集时间及缺口提示。
- 导出到本机后恢复，手记图片完整；损坏或格式错误的备份不会清空当前数据。
- 窄屏、大字体、横屏、键盘和手势导航下，关闭、保存、日期与时间选择均可操作。

请记录实际机型、系统版本、日期、通过项与失败项。不要把未采集到的记录当成零使用，也不要把模拟器结果写成真机准确率。
