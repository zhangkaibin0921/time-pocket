# 隐私与数据说明

适用于本仓库 v0.6.8 源码所构建的应用。

## 保存什么

应用在自身私有存储中保存应用名称与包名、图标缓存、系统使用事件、汇总片段、安装卸载记录、采集完整性信息，以及用户填写的手记、图片和睡眠调整。

没有账号、广告或分析 SDK，没有声明 Android `INTERNET` 权限，不向开发者上传使用记录，也未启用 Android 自动备份。

## 图片

添加图片使用系统文件选择器，仅处理用户选择的文件，不扫描相册，不申请相册读取或相机权限。

每条手记最多 3 张图片。导入时校正方向、缩放并生成 JPEG 副本，最长边不超过 1600 像素，每张不超过 256 KB；透明区域铺白，动图保存为静态画面。原文件保持原样。

图片草稿先放缓存，确认保存后与手记一起写入数据库。移除、放弃或保存后清理相应草稿；异常退出遗留的缓存会在后续导入时清理超过 7 天的文件。删除手记会同时删除其已保存附件。

## 导出与删除

JSON 备份包含应用使用与生活记录，以及编码后的图片；没有额外的文件加密。请保存在自己信任的位置，反馈问题时不要公开上传原始备份。

导出或恢复由用户通过系统文件选择器发起。若选择第三方云盘，文件可能由对应服务上传或下载，这不属于时光口袋内置的联网功能。

卸载应用或清除应用数据会移除其私有数据；用户已导出的备份文件不随之删除，需要自行管理。撤销使用情况访问权限会停止后续可授权的读取，已经保存的历史仍可查看。
